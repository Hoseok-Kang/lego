# 블록 이미지 빌더 + 블록 성 지키기 + 펑펑 토끼

이 저장소에는 세 가지가 들어 있습니다.

- **펑펑 토끼** (`fight.html`): 블록으로 만든 내 토끼가 미친토끼 5마리와 싸우는 탑뷰 총싸움·칼싸움
- **블록 성 지키기** (`game.html`): 그림으로 만든 블록 성을 타워로 지키는 3D 디펜스 게임
- **블록 이미지 빌더** (`index.html`): 그림을 작은 블록으로 바꿔서 아래부터 쌓아 올리는 모션

# 펑펑 토끼

미리보기 링크: https://claude.ai/artifact/SuDwefZPgy2zph7o2NLU6i

토끼, 칼, 총, 상자, 나무까지 모두 블록으로 만든 작은 전장에서 미친토끼 5마리를 모두 '펑!' 터뜨리면 이겨요.
맞으면 **토끼 귀 블록이 끝에서부터 톡톡 터지고**, 체력이 0이 되면 **'펑!' 하고 몸 전체가 블록으로 흩어져** 바닥에 쌓여요.

## 하는 방법

| | 컴퓨터 | 휴대폰 |
| --- | --- | --- |
| 움직이기 | W A S D (화살표) | 왼쪽 아무 데나 대고 끌기 |
| 조준·공격 | 마우스로 조준, 왼쪽 버튼 (누르고 있으면 계속) | **공격** 단추: 누르면 가까운 미친토끼 자동 조준, 끌면 그쪽으로 |
| 점프 | Space · Shift · 오른쪽 버튼 | **점프** 단추 (공격 단추 오른쪽) |
| 무기 바꾸기 | Q · 마우스 휠 · 1 / 2 | **총⇄칼** 단추 |
| 장전 · 멈춤 | R · Esc | 장전 단추 · 오른쪽 위 멈춤 |

- **블록 총**: 누르고 있으면 계속 쏴요. 14발을 다 쏘면 저절로 장전해요.
- **블록 칼**: 넓게 휘둘러요. 날아오는 미친토끼 총알을 튕겨 낼 수 있어요.
- **점프**: 공중에 떠 있는 동안은 맞지 않아요 (총알은 발밑으로, 칼 찌르기·망치 내려치기도 피함). 공중에서도 쏘고 휘두를 수 있어요.
- **미친토끼 3종**
  - 칼 토끼: 빨갛게 반짝이면 곧 휙 찔러요 → 옆으로 비키거나 점프
  - 총 토끼: 총구가 반짝이면 세 발씩 쏴요 (분홍 총알)
  - 망치 토끼: 크고 튼튼해요. 바닥에 빨간 원이 차오르면 원 밖으로 나가거나 점프
- **당근**: 먹으면 체력이 30 차고, 터졌던 귀 블록이 위에서 떨어져 다시 쌓여요. 미친토끼나 상자가 부서질 때 가끔 나와요.
- **나무 상자**: 총알·칼에 맞으면 블록이 조금씩 떨어져 나가다가 부서져요.

# 블록 성 지키기

미리보기 링크: https://claude.ai/artifact/JqxfFRe6eKQK16cxsjjbPK

## 하는 방법

1. **게임 시작**을 누르면 가운데 성이 블록으로 쌓여요.
2. 성 둘레의 **타워 자리(모래색 판)**를 누르면 타워를 골라 지을 수 있어요. 타워는 블록이 다 쌓여야 공격해요.
   - 화살 타워: 빠르게 쏴요 / 대포 타워: 여러 마리를 한꺼번에 맞혀요 / 얼음 타워: 맞은 몬스터를 느리게 해요
   - 지은 타워를 다시 누르면 **강화**(위에 노란 왕관 블록이 쌓임)하거나 **팔 수** 있어요.
3. 성 바로 옆의 **노란 + 자리**를 누르면 **성 부품**을 붙여서 성을 키울 수 있어요.
   - 모서리: 망루(화살), 대포 포대(넓게 터지는 대포)
   - 옆면: 성벽(성 체력 +, 그쪽 공격을 먼저 막음), 창고(웨이브마다 돈), 수리소(수리량 +, 타워 빨리 짓기)
   - 부품도 강화하면 층이 위로 쌓여 성이 점점 커져요.
4. 쉬는 시간에는 바닥에 **빨간 화살표**로 다음 몬스터가 올 방향을 미리 보여 줘요.
5. 몬스터는 맞을 때마다 **몸에서 블록이 떨어져 나가요**. 남은 블록이 곧 남은 체력이에요.
   떨어진 블록은 **잔해로 바닥에 남아 있다가, 대장이 나올 때 한곳으로 모여서 대장 골렘이 돼요.**
6. 웨이브를 막을 때마다
   - **땅이 넓어져요** (둘레에 잔디 블록이 촤르륵 쌓임). 넓어지면 바깥쪽에 **새 타워 자리**가 생기고, 몬스터는 더 멀리서 와요.
   - **보상 카드 3장 중 하나**를 골라요 (타워 강화, 돈, 새 스킬, 무료 성 부품 등).
   - 성이 조금 **수리**돼요 (떨어진 블록이 다시 쌓임).
7. 아래 **스킬 단추**: 블록 떨어뜨리기(단추를 누른 뒤 땅을 눌러요), 얼려라·긴급 수리(카드로 열려요).
8. 10웨이브를 모두 막으면 승리!

**내 그림 넣기**: 내 사진이나 그림을 **우리 성, 타워, 몬스터** 모습으로 바꿀 수 있어요. 새 몬스터(내 몬스터)로 추가할 수도 있어요.
배경이 투명한 PNG 그림이 가장 잘 어울려요. 넣은 그림은 이 브라우저에 저장돼서 다음에 열어도 남아 있어요.

# 블록 이미지 빌더

그림이나 사진을 아주 작은 네모 블록으로 바꾼 뒤, 블록이 맨 아래부터 하나씩 떨어져 쌓이면서 그림이 완성되는 3D 모션을 보여 줍니다.
나중에 게임으로 키울 수 있도록 기능마다 파일을 따로 나눠 두었습니다.

## 할 수 있는 것

- **토끼 예시**: 처음 열면 당근을 든 토끼가 블록으로 쌓입니다.
- **사진 올리기**: 내 사진을 올리거나, 화면에 끌어다 놓거나, 붙여넣으면(Ctrl+V) 그 사진으로 쌓습니다.
  배경이 투명한 PNG는 모양대로만 쌓입니다.
- **가로 블록 수**: 숫자가 클수록 블록이 작고 많아져서 더 자세해집니다.
- **쌓는 속도 / 순서**: 랜덤, 왼쪽부터, 가운데부터, 지그재그 중에서 고릅니다.
- **색 섞기**: 사진처럼 부드러운 색 변화를 블록 색을 섞어서 표현합니다.
- **소리**: 블록이 앉을 때 '딸깍', 완성되면 짧은 멜로디가 나옵니다.
- **부품 목록**: 조립 설명서처럼 어떤 색 블록이 몇 개 필요한지 보여 줍니다.
- 화면을 끌면 돌려 볼 수 있고, 휠이나 두 손가락으로 확대할 수 있습니다.

## 실행하는 방법

`index.html`을 더블클릭하면 브라우저 보안 규칙 때문에 화면이 비어 보입니다.
아래 둘 중 하나로 열어 주세요.

1. 미리보기 링크로 열기 (가장 쉬움): https://claude.ai/artifact/CrKQK7XD7JTvQErszExVrv
   처음에는 만든 사람만 열 수 있고, 다른 사람에게 보여 주려면 페이지의 공유 메뉴에서 공유하면 됩니다.
2. 이 폴더에서 간단한 웹 서버를 켜고 열기: `npx serve .` 를 실행한 뒤 안내되는 주소를 브라우저로 엽니다.

`media/` 폴더에는 토끼가 쌓이는 영상(`rabbit-build.mp4`)과 완성 그림(`rabbit-final.png`)이 있습니다.

## 게임으로 키울 때

`js/bricks/buildPlan.js`가 만드는 **블록 목록**(위치, 색, 쌓는 순서)이 게임의 기본 재료가 됩니다.
예를 들어 점수, 시간 제한, 플레이어 조작 같은 기능은 새 파일(예: `js/game/…`)로 만들고 `js/main.js`에서 연결하면 지금 있는 파일을 거의 건드리지 않고 붙일 수 있습니다.

## 영상으로 뽑기 (`tools/`)

화면을 한 장면씩 찍어서 소리를 입힌 영상(mp4)으로 만듭니다. 컴퓨터에 Node.js, Python, ffmpeg가 있어야 합니다.

1. `npm install` 후 `npm run serve` 로 웹 서버 켜기
2. 다른 창에서 `npm run record` → `recording/frames/` 에 장면 그림이 쌓임
3. `python3 tools/make-click-audio.py recording/events.json recording/audio.wav` 로 효과음 만들기
4. `tools/make-click-audio.py` 맨 위에 적힌 ffmpeg 명령으로 영상 합치기
