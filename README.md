# 블록 이미지 빌더

그림이나 사진을 아주 작은 네모 블록으로 바꾼 뒤, 블록이 맨 아래부터 하나씩 떨어져 쌓이면서 그림이 완성되는 3D 모션을 보여 줍니다.
나중에 게임으로 키울 수 있도록 기능마다 파일을 따로 나눠 두었습니다.

## 할 수 있는 것

- **토끼 예시**: 처음 열면 당근을 든 토끼가 블록으로 쌓입니다.
- **사진 올리기**: 내 사진을 올리거나, 화면에 끌어다 놓거나, 붙여넣으면(Ctrl+V) 그 사진으로 쌓습니다.
  배경이 투명한 PNG는 모양대로만 쌓입니다.
- **가로 블록 수**: 숫자가 클수록 블록이 작고 많아져서 더 자세해집니다.
- **쌓는 속도 / 순서**: 랜덤, 왼쪽부터, 가운데부터, 지그재그 중에서 고릅니다.
- **색 섞기**: 사진처럼 부드러운 색 변화를 블록 색을 섞어서 표현합니다.
- **소리**: 블록이 앉을 때 '딸깍', 완성되면 짧은 멜로디가 나옵니다.
- **부품 목록**: 조립 설명서처럼 어떤 색 블록이 몇 개 필요한지 보여 줍니다.
- 화면을 끌면 돌려 볼 수 있고, 휠이나 두 손가락으로 확대할 수 있습니다.

## 실행하는 방법

`index.html`을 더블클릭하면 브라우저 보안 규칙 때문에 화면이 비어 보입니다.
아래 둘 중 하나로 열어 주세요.

1. Claude가 만들어 준 미리보기 링크로 열기 (가장 쉬움)
2. 이 폴더에서 간단한 웹 서버를 켜고 열기: `npx serve .` 를 실행한 뒤 안내되는 주소를 브라우저로 엽니다.

## 동작 순서

```
그림 ─▶ 격자로 나누기 ─▶ 블록 색 고르기 ─▶ 쌓기 계획 ─▶ 3D 블록 ─▶ 쌓기 모션
        pixelator       colorMatcher     buildPlan    blockMeshes  stackAnimator
```

## 파일 지도: 무엇을 바꾸려면 어디를 보면 되나요

| 파일 | 하는 일 | 이럴 때 고치세요 |
| --- | --- | --- |
| `js/config.js` | 모든 숫자 설정 | 블록 크기, 떨어지는 높이, 속도, 카메라 각도, 바닥판 색 |
| `js/bricks/brickColors.js` | 블록 색 목록 | 쓸 수 있는 블록 색을 넣거나 빼기 |
| `js/image/sampleRabbit.js` | 토끼 예시 그림 | 처음에 나오는 예시 그림 바꾸기 |
| `js/image/imageLoader.js` | 사진 불러오기 | 사진 넣는 방법, 파일 크기 제한 |
| `js/image/pixelator.js` | 그림을 칸으로 나누기 | 칸 색을 고르는 방법 |
| `js/bricks/colorMatcher.js` | 가장 비슷한 블록 색 찾기 | 색 맞추는 방법, 색 섞기 |
| `js/bricks/buildPlan.js` | 블록 목록과 쌓는 순서 | 새로운 쌓기 순서 추가 |
| `js/scene/stage.js` | 3D 무대, 조명, 바닥판 | 밝기, 그림자, 배경 분위기 |
| `js/scene/blockMeshes.js` | 블록 모양 | 블록 모서리, 돌기 모양 |
| `js/scene/cameraRig.js` | 카메라 움직임 | 보는 각도, 화면 돌리기 |
| `js/motion/stackAnimator.js` | 떨어지고 튀는 움직임 | 착지 느낌, 튀는 모양 |
| `js/motion/easing.js` | 움직임 곡선 | 묵직함/가벼움 |
| `js/audio/clickSound.js` | 효과음 | 딸깍 소리, 완성 멜로디 |
| `js/ui/controlPanel.js` | 버튼·슬라이더 연결 | 조작판 동작 |
| `js/ui/partsList.js` | 부품 목록 | 목록 표시 방식 |
| `js/core/frameLoop.js` | 화면 갱신 반복 | 거의 바꿀 일 없음 |
| `js/main.js` | 위 파일들을 연결 | 새 기능을 끼워 넣을 때 |
| `index.html` | 화면에 보이는 글자와 버튼 | 문구 바꾸기 |
| `css/style.css` | 색과 배치 | 화면 색, 글꼴, 크기 |
| `vendor/three/` | 3D 그리기 도구 three.js (MIT 라이선스) | 바꾸지 않음 |

## 게임으로 키울 때

`js/bricks/buildPlan.js`가 만드는 **블록 목록**(위치, 색, 쌓는 순서)이 게임의 기본 재료가 됩니다.
예를 들어 점수, 시간 제한, 플레이어 조작 같은 기능은 새 파일(예: `js/game/…`)로 만들고 `js/main.js`에서 연결하면 지금 있는 파일을 거의 건드리지 않고 붙일 수 있습니다.
